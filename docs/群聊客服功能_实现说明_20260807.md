# 群聊客服功能 — 实现说明（2026-08-07）

> 按 `docs/群聊客服功能_功能交接.md` 实现。本文件记录实现位置与待验证项。

## 已实现

### 新模块 `group_chat_handler.py`
| 方法 | 行为 |
|---|---|
| `detect_at_mention(context, account_name)` | 最新对方消息开头 @ + 用户名（容错：@ 后第一个词与用户名相等/互为前缀，兼容 `@程 正恒` OCR 空格变体） |
| `extract_question(message, account_name)` | 去 @用户名 前缀 + 分隔标点（`：:，,。`），剩余为问题 |
| `extract_sender_name(context)` | 发送者名字去平台标记（`@-@微信`/`@微信`/`(企业微信)`/`(微信)`/`·微信`/`·企业微信` 等 11 种变体；保留名字本身符号如 `-`）；兼容 OCR 单行合并与上下双行格式 |
| `build_reply(sender_name, reply_content)` | `@发送者名字 回复内容`（文字 @） |
| `is_chat_idle(context, account_name)` | 对方消息没 @ 我 = 聊天内容无变化 |

### settings.py
- `wecom_account_name: str = ""`（当前账号用户名，持久化）
- `group_poll_interval_ms: int = 800`（群聊 OCR 轮询间隔）

### float_ui.py
- "当前账号用户名"输入框：模式行下方、上下文面板上方，`FocusOut/Enter` 修改即存（`_save_account_name`）

### main.py
- `start()`：用户名首次为空 → `root.after(900)` 弹 `askstring` 提示填写并保存
- `_poll_interval()`：群聊用 800ms、其他 1200ms（`_monitor_loop` 三处 sleep 已替换）
- `_process_window`：群聊（`current_chat_type=="group"`）不走个人主路
- `_after_switch`：group → `_handle_group_chat`（@ 我 → extract_question → `engine.generate` 复用现有决策链 → `build_reply` → 后台线程发送；没 @ → 不回复）
- `_conversation_list_bypass`：群聊无变化（group_idle）也触发列表扫描；@ 我时不触发
- `ChatStateGuard.should_start_scan`：新增 `chat_type/group_idle` 参数，群聊"我方发出 或 对方没@我"都能触发
