# 会话列表自动切换 + 会话类型四分类 — 实现说明（2026-08-07）

> 按 `会话列表自动切换_功能交接.md` 实现。本文件记录实现位置、降级项与待验证项。

## 已实现

### 新模块 `conversation_list.py`
| 类 | 职责 |
|---|---|
| `ConversationListMonitor` | 左侧列表红点像素检测（RGB R≥230/G≤90/B≤90，BFS 连通块 + 直径过滤 + 大色块排除），返回按 y 排序的 `RedDotHit`；`click_point_for` 返回该行头像区点击坐标 |
| `ChatIdentityTracker` | 当前会话标识 = 顶部标题 OCR 文字（hwnd 不变，必须用标题） |
| `ChatStateGuard` | 触发（托管 + 我方最新消息持续 2 秒 + 2 秒扫描间隔 + 非暂停期）；6 种打断（对方新消息/用户输入/发送中/处理中/不在前台/重试中） |
| `ConversationTypeDetector` | 四分类：system（白名单精确 + 前缀 + 关键词兜底）→ group（3×3 子块**边界主色跳变**，非整体色彩丰富度，规避合影头像陷阱）→ personal（子块差异小）→ unknown |
| `load_calibration` | 加载 `wecom_5_calibration.json`，失败回退内置默认 |

### `main.py` 旁路集成
- 新增状态：`chat_identity / chat_state_guard / chat_list_monitor / chat_type_detector / bypass_*`（含 `bypass_paused_until`、`force_refresh`）
- `_monitor_loop` 末尾调 `_conversation_list_bypass(wechat)`（主路零改动，异常隔离）
- `_bypass_try_switch`：全窗截图 → 红点扫描 → 选 y 最小红点 → pyautogui 点击头像区 → 等 1.2 秒 → 顶部标题变化 + 红点消失双重确认 → 失败重试 1 次 / 换下一红点 → 连续 3 次失败：`bypass_alert` UI 提示 + 暂停 5 分钟
- `_after_switch`：清空 `current_hash/current_context/managed_last_handled_*` → `force_refresh=True` → 四分类分流：system 跳过不回复 / group 提示"群聊功能待补齐"（分支预留）/ personal 走主路 / unknown 提示留待人工
- `_user_typing_detected`：GetAsyncKeyState 轮询 + 1.5 秒时间戳窗口
- `_show_bypass_alert`：屏幕正中央 + 置顶 + winsound 提示音（`bypass_alert` 队列消息）
